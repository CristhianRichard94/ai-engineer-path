Task: Build a CLI tool in Python that indexes a GitHub repo's documentation and allows you to ask questions about it.

Requirement 1: Implement a "Hybrid Search" (Vector search + Keyword search/BM25).

Requirement 2: Use Reranking (e.g., Cohere Rerank) to improve the top 5 results before sending them to the LLM.

Requirement 3: Add a TypeScript/React frontend that streams the response (SSE/WebSockets).
